# Características y Módulos Técnicos

Detalle técnico de los módulos y capacidades SaaS de Club Digital Pro.

---

## 🎨 Motor de Personalización (Custom Branding)
- **19 Variables CSS de Color:** Inyectadas dinámicamente en el `document` HTML para re-estilizar toda la UI sin recargar página.
- **Tipografías Google Fonts:** Carga asíncrona de fuentes comerciales seleccionadas por el administrador de cada club.

## 👥 Centro de Socios
- **Ficha Digital:** Registro de datos personales, médicos y parentescos familiares.
- **QR Engine:** Generación de credenciales con código QR único para validación de acceso rápido en portería.

## 💳 Cuotas y Finanzas
- **Pasarela Mercado Pago:** SDK preparado para cobros y suscripciones recurrentes con webhook de confirmación.
- **Generación de Facturas:** Base de datos relacional para guardar recibos y auditoría de caja.

## 📺 Newbery TV Streaming
- **Enlace RTMP/YouTube:** Incrustación de reproductores de transmisión y conmutación de cámaras (Multi-cámara).
- **Gemini Tactic Reviewer:** Algoritmo que analiza los eventos del partido y genera un resumen escrito en lenguaje natural.

## 📊 Analytics Sponsors
- **CTR (Click Through Rate):** Registro de vistas e impresiones de banners publicitarios comerciales para justificar auspicios.
